# CM-FDI data dictionary

Edition 2026.09. Generated by `bin/build_release.py` from the working workbook, so this file cannot describe a column the CSV does not have.

`cm-fdi-projects.csv` holds **926 projects** across **26 fields**, with announcement years from 1997 to 2026.

The interactive explorer charts 2001 to 2026 and clamps anything earlier into its first year, so 1 project here sits at a different year there: FDI95074 (LM Wind Power (LM Glasfiber), 1997). The CSV keeps the announced year; the chart does not.

## Before you use the capital column

**815 of 926** projects report a capital value; **111** do not, and read as 0. Summing the column therefore understates total announced capital by an unknown amount, and any per-project average must be taken over the 815 disclosed rows rather than all 926. Figures are announced or reported capital, not audited spend.

**853 of 926** projects are manufacturing; the rest are R&D, design and logistics. The working paper's regressions use the manufacturing subset. Decide which universe you want before you compare a figure here with one from the paper.

## Fields

Every substantive field carries its own `Source (...)` column rather than the row holding one citation, so a reader can check a single number without having to accept the whole row.

| # | Field | Definition |
|---|---|---|
| 1 | `Sector` | Clean technology the project belongs to. One of Battery, Solar, Wind, EV. |
| 2 | `Project ID` | Stable identifier for the project within this dataset. |
| 3 | `Parent company` | Ultimate parent making the investment, not the local subsidiary. |
| 4 | `Company Country (HQ)` | Economy where the parent is headquartered. The home economy of the investment. |
| 5 | `Project Status` | Status as last reported by the source. |
| 6 | `Destination Country` | Economy receiving the investment. The host economy. |
| 7 | `Destination city` | City or region, as reported. Geocoded to coordinates for the explorer map. |
| 8 | `Year Announced` | Year the project was first publicly announced. A small number of rows carry N/A here and are dated from Year Completed instead. |
| 9 | `Year Completed` | Year the project became operational. N/A where not yet complete or not reported. |
| 10 | `Technology` | Technology of the plant. Mirrors Sector in the current release. |
| 11 | `Industry activity` | What the facility does. Manufacturing, R&D, design, or logistics. |
| 12 | `Capital Investment (US$m)` | Announced or reported capital in US$ millions. This is announced capital, not audited spend, and not a measure of what was ultimately built. Blank or 0 means the value was not disclosed, which is a gap in disclosure rather than a project without capital behind it. Do not sum this column without also reporting how many rows are undisclosed. |
| 13 | `Expansion` | 1 where the project expands an existing site rather than building a new one. |
| 14 | `Joint Venture` | 1 where the project is a joint venture. |
| 15 | `Joint Venture Local` | 1 where at least one JV partner is based in the destination economy. |
| 16 | `Joint Venture Company` | Named partner or partners in the joint venture. |
| 17 | `Source (Parent company name and HQ)` | Public source for the field named in brackets. |
| 18 | `Source (Project Status)` | Public source for the field named in brackets. |
| 19 | `Source (Project location, country and city)` | Public source for the field named in brackets. |
| 20 | `Source (Amount)` | Public source for the field named in brackets. |
| 21 | `Source (Ownership share, where available)` | Public source for the field named in brackets. |
| 22 | `Source (Date Announced [MM/DD/YYYY])` | Public source for the field named in brackets. |
| 23 | `Source (Date Completed [MM/DD/YYYY])` | Public source for the field named in brackets. |
| 24 | `Source (Industry Activity)` | Public source for the field named in brackets. |
| 25 | `Source (Joint Venture)` | Public source for the field named in brackets. |
| 26 | `Operational` | Normalised operating state, collapsing the reported statuses into fewer classes. |
